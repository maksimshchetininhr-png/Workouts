How load suggestions work

Known baselines are used first. Once you log a lift, the app looks at your last non-deload session: it suggests adding load when every set hit the top of the rep range with reps to spare, repeating otherwise, and dropping about 10% if pain went above 2/10. Deload weeks use about 85% of your last load. Machine stacks are calibrated by RIR.

Rest timer

The timer starts when a set has its reps (and load, where needed). Defaults: 3:00 heavy strength, 2:00–2:30 compound lifts and carries, 1:30 accessories, 1:00 core and prehab. Tap +30s whenever you're not ready to repeat the set with good technique.

Install on iPhone
