# Strength + Shoulder Capacity + Progressive Knee Rehabilitation

Weeks 5-12 of the 12-week programme (starting 7 November 2026). Existing Weeks 1-4 are preserved.

**Safety:** Return to baseline by next morning; pain no greater than 3/10. With partial tendon tear history, get physiotherapist clearance before progressing from isometrics. If not cleared, repeat previous phase.

**App logging:** For isometric holds, use the reps box for **seconds** and leave weight blank when unloaded. For farmer carries, reps means metres.
